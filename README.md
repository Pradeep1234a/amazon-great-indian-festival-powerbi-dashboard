# Amazon Great Indian Festival 2026 — Power BI Dashboard

## 📊 Project Overview

This project presents an interactive Power BI dashboard designed to analyze Amazon Great Indian Festival sales performance. It transforms sales data into meaningful business insights through KPI cards, charts, and interactive filtering.

## 🎯 Project Objectives

- Monitor overall sales performance and GMV.
- Analyze total savings distributed and orders placed.
- Track Prime member orders and on-time delivery performance.
- Compare sales performance across regions.
- Explore category sales mix by membership type.
- Analyze transactions by payment method.
- Evaluate bank promotional discounts and order status.

## 📌 Dashboard Features

- **KPI Cards:** Total GMV, Savings Distributed, Orders Placed, Prime Member Orders, and On-Time Delivery Rate.
- **Regional Sales Performance:** Compare sales across regions.
- **Category Sales Mix by Membership:** Analyze category sales distribution across membership types.
- **Transactions by Payment Method:** Understand payment preferences.
- **Bank Promotional Discount Value:** Examine promotional discounts.
- **Live Order Status:** Visualize the distribution of order statuses.
- **Interactive Filtering:** Explore results using the Order Type slicer.
- **Fulfillment Speed Distribution:** Examine order fulfillment patterns.
